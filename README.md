# Playerok Telegram Mini App

Мобильный маркетплейс на React + TypeScript + Vite, подготовленный для публикации на Vercel.

## Запуск локально

1. Установи Node.js 20 или новее.
2. Открой терминал в папке проекта.
3. Выполни команды:

```bash
npm install
npm run dev
```

Открой адрес Vite, который появится в терминале (обычно `http://localhost:5173`). Не открывай `index.html` двойным кликом.

## Публикация на Vercel

1. Загрузи папку проекта в GitHub.
2. Импортируй репозиторий в Vercel.
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажми Deploy.

## Подключение профиля Telegram

Mini App читает `Telegram.WebApp.initDataUnsafe.user` и подставляет имя, фамилию, username, Telegram ID, язык и фото профиля, если Telegram передал `photo_url`.

Чтобы Telegram передавал пользователя, открой настройки `@Playerok_Guarantor_Bot` через BotFather и задай Menu Button / Web App URL, указывающий на опубликованный Vercel URL. Затем запускай приложение именно через кнопку меню бота или Web App-кнопку в сообщении. При обычном открытии ссылки в браузере Telegram-профиль недоступен.

Важно: Telegram прямо предупреждает, что `initDataUnsafe` нельзя использовать для доверенной аутентификации. В этой версии данные используются для отображения профиля; серверная проверка `initData` и защищённые пользовательские операции не реализованы. Не используй данные на клиенте для подтверждения платежей, прав доступа или владения товарами.

## Доступ к панели администратора

Пункт **Управление каталогом** показывается только двум Telegram-аккаунтам с ID `8491418744` и `9264762756`. Эти ID зафиксированы в серверном файле `api/admin-check.ts`; другие пользователи не получают админ-доступ. При каждом запуске backend-функция `/api/admin-check` проверяет подпись `Telegram.WebApp.initData` с помощью токена бота. `initDataUnsafe` используется только для отображения профиля, но не для выдачи прав.

### Настройка на Vercel

В проекте Vercel открой **Settings → Environment Variables** и добавь:

- `BOT_TOKEN` — токен бота из BotFather. Вставляй его только в Vercel; не добавляй в GitHub, frontend-код или чат.

Сохрани переменные для **Production** (и Preview, если проверяешь Preview-деплои), затем открой **Deployments → Redeploy** для последнего Production-деплоя. Если переменные не заданы или пользователь открыл сайт вне Telegram, админ-доступ закрыт.

Переменная `ADMIN_IDS` не используется: список администраторов уже указан в `api/admin-check.ts`. Если ты ранее добавлял `ADMIN_IDS` в Vercel, можешь удалить её — она не влияет на доступ. Никогда не публикуй `BOT_TOKEN`.

**Важно:** сейчас добавление и удаление подарков сохраняется в браузере администратора (локальное хранилище). Другие посетители не получат эти изменения автоматически. Для общего каталога всем покупателям нужно подключить базу данных и серверные API для операций записи.

## Темы и логотипы

При первом открытии по умолчанию открывается вкладка Market и включена тёмная тема. В шапке находится переключатель светлой и тёмной темы; после ручного переключения выбор сохраняется на устройстве. Для нового значения по умолчанию используется отдельный ключ настроек темы. Логотипы находятся в `public/playerok-wordmark.png` и `public/playerok-symbol.png`.

## Добавление подарков в каталог

В панели администратора достаточно вставить ссылку на NFT, например `https://t.me/nft/JellyBunny-12779`. Приложение автоматически заполнит коллекцию, номер и ссылку на изображение Fragment. Модель, фон, узор и их проценты редкости нужно ввести вручную. При необходимости можно раскрыть дополнительные настройки изображения и вставить собственный URL.

Изображение обычно можно открыть прямо на Fragment по шаблону `https://nft.fragment.com/gift/название-коллекции-номер.webp`; отдельный поиск и копирование URL изображения больше не обязательны.

## Текущее поведение

Пять основных вкладок, поиск, сортировка по номеру, карточки Telegram-подарков с моделью/фоном/узором/редкостями, переключение языка и темы. Покупка, пополнение и вывод средств отображаются как недоступные элементы интерфейса.

## Добавление подарков

В панели администратора вставь в поле NFT link ссылку формата `https://t.me/nft/JellyBunny-12779`. Приложение само определит коллекцию и номер, а изображение возьмёт из публичного NFT-превью Fragment. Вручную заполни только модель, фон, узор и (при желании) их редкости. Открывать дополнительные настройки изображения нужно только если хочешь указать собственную картинку.
